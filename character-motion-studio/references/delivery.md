# 角色动画实验室 0.2 — 使用与交付

双击「角色动画实验室.html」，用浏览器打开。素材、React、形变引擎和导出库均已内嵌，离线可用。视频导出需要浏览器提供 WebCodecs 编码能力；工具会检查实际支持情况，不会用其他格式改后缀冒充。

## 本轮新增

- 界面改为黑白灰，角色保留原画配色。
- Curve：Hold、Linear、Ease in、Ease out、Ease in and out、三个 Back 变体、Custom bezier。控制点可以拖动，也可输入四个数值。
- Spring：Gentle、Quick、Bouncy、Slow、Custom spring，可编辑刚度、阻尼、质量。弹簧按设置时长归一到终点，参考 Figma 的交互方式，不承诺与其私有参数逐值等价。图表绘制实际驱动的进度；过冲用于轮廓，而透明度和镂空范围有限制。
- 两个状态的行为设置同时显示：呼吸、眨眼、视线、挥手、旋转/气流、Wink、跳跃。工作态没有独立手部，因此对应挥手控制会禁用并说明原因。
- 每个状态行为的滑杆旁都有可直接键入的数值框；输入会限制在当前参数的安全范围内。
- 可手动选择一对 SVG（工作态在前、目标态在后）。此案例将每份文件的前 5 条路径视为相同顺序的共享部件；复杂素材仍须先整理路径对应关系。
- 可复制 Framer、Figma、HTML iframe 和设置 JSON 的嵌入内容。导出 HTML 需先发布到可访问地址，才能替换嵌入代码中的占位地址；本地文件本身不能生成公开 URL。
- 右侧导航可快速到达缓动、分层、行为、画布、导出。所有设置均列在滚动面板中；HTML 导出保留整个编辑器。
- 过渡曲线和时长在下一次切换生效；行为参数随设置更新。

## JSON 是什么

「导出设置 JSON」保存本工具的曲线、时长、分层过渡方式、各状态行为、锚点、背景和导出参数；「从 JSON 恢复设置」将这些参数重新载入。它不含 SVG 原画，不是 Lottie JSON，也不是 Rive 状态机。分享完整项目应优先使用「导出 HTML」。恢复默认会重置本工具的全部设置。

## 导出格式

|格式|内容|透明度|继续编辑|
|---|---|---|---|
|HTML|完整交互编辑器、素材、当前设置|支持|可继续调参、切换角色并再次导出|
|JSON|本工具参数|不适用|载回本工具修改|
|静态 SVG|当前目标状态的初始静态造型，带分层矢量|支持|可在矢量软件中编辑外形|
|动画 SVG|按帧率采样的 SMIL 矢量播放文件|支持|可编辑文件结构，但不是稀疏关键帧工程；不保留交互|
|PNG|静态图片|支持|位图编辑|
|GIF|所选片段的位图动图|仅二值透明|不保留分层和交互|
|MP4|H.264 视频|本版不支持 Alpha，合成到铺底色|视频剪辑，不含矢量图层|
|WebM|VP9 视频|本版不支持 Alpha，合成到铺底色|视频剪辑，不含矢量图层|
|AE JSX（实验）|根据片段生成分层路径与透明度关键帧的脚本|矢量与减法蒙版|需 AE 实际运行确认；本机调用超时，未验证导入成功|
|Rive 准备素材 ZIP|两个带部件 ID 的原始 SVG、参数、说明|SVG 支持|需在 Rive 内重新创建动画和状态机；不是 .riv|

Size 为 0.25×、0.5×、1×、1.5×、2×；1× 输出 1000×1000。视频/GIF 可选 Low、Medium、High。SVG/PNG 为无损内容，因此 Quality 不适用。帧率支持 12/15/24/30/60 fps。GIF 以 10ms 为延迟单位，采用交替帧延迟近似所选帧率。

动画片段可选当前状态待机、正向、反向、往返；可指定待机时长或每段停留时间。视频输出是固定时长片段，播放器决定是否循环；GIF/动画 SVG 可写入循环标记。界面显示预计尺寸与时长，视频大小是码率估算，完成后显示实际文件大小。

AE 的路径采样选项独立于视频质量：64/112/192 点。脚本设计为通过 AE 的 File → Scripts → Run Script File 新建合成，然后在 AE 内另存 AEP。路径是采样的密集关键帧，便于修改，但不会恢复原始手绘控制柄、骨骼或交互状态机。目前生成和语法检查已完成，AE 2025 AppleEvent 执行调用超时，故未交付经过验证的 AEP 文件。

Rive 支持将 SVG 导入为可编辑矢量内容：[官方资产说明](https://rive.app/docs/editor/fundamentals/assets-overview)。AE 支持 ExtendScript 自动化：[官方脚本说明](https://helpx.adobe.com/after-effects/desktop/automate-in-after-effects/automate-animation/scripts.html)。本工具的输出能力以本表为准。

## 原画部件映射

两个 SVG 为 1000×1000，无原始分层 ID。本轮根据路径顺序建立对应：

|部件|工作总.svg 路径序号（从 1 开始）|接受文档.svg 路径序号|
|---|---|---|
|body-main|1|1 的外轮廓|
|body-shadow|2|2|
|face-main|3|4|
|eye-left|4|5|
|eye-right|5|6|
|加载器|6–13|无|
|电脑|14–19|无|
|嘴边阴影|无|3|

|气流|无|8–12|

接受文档路径 1 的第二子路径为嘴部镂空，HTML 使用透明蒙版。Rive 素材包保留原始复合路径。原画没有独立文档图形，本轮不额外绘制纸张，仅动画化气流。

## 验收记录

在本机 Chrome 执行了以下检查：

- 9 个 Curve 选项与 5 个 Spring 选项均可切换，Spring 响应包含真实过冲。
- 连续 14 次中途反向，无 JavaScript 错误；位置从当前轮廓接续，未承诺速度的一阶连续。
- 两状态参数互不串改，HTML 再次导出后可以单独打开。
- PNG、静态 SVG、动画 SVG、GIF、MP4、WebM 与 JSX 均生成实际文件。
- MP4/WebM 通过浏览器解码检查尺寸、时长及非空画面；GIF 用独立图像库核对帧数、时长及透明像素；SVG 通过 XML 解析和浏览器画面检查。
- 默认 MP4：1000×1000、30 fps、72 帧、2.4 秒，实际文件约 1.02 MB。
- 取消导出后无残留捕获场景；Rive ZIP 中 SVG 的 ID 唯一且包含共享部件。
- 390px 窄屏无横向溢出；离线测试没有 HTTP 请求。

AE 导入与 Rive 原生状态机没有验证通过，不能用浏览器导出检查代替。
